# 开发说明

## 版本与环境

当前版本为 v1.8.3。版本用途及分支约定见 [版本说明](VERSIONS.md)。日常改进以 `main` 为起点。

需要 Windows、Python 3.12 和 WebView2 Runtime。v1.6.4 的门户兼容还需要系统已有 Edge 或 Chrome；当前 Windows 生产包使用独立 WebView2 控件。

在仓库根目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe campus_app.py
```

## 登录与注销

产品提供登录、注销和手动检测状态。每次登录只提交一次认证请求，保留学校原始回执，并区分已接受、已在线、认证超时和实际查询状态。只有绑定本机的状态证据能够更新当前在线身份，不能把“终端 IP 已在线”当作新输入账号登录成功。其他明确拒绝在结果反馈后清除门户发现缓存，下一次用户操作重新发现接入参数，不在同次操作里重发认证。原生认证不支持当前页面时，原网页兼容流程仍须遵守可信端点、源网卡及单次提交约束。

认证超时（`ret_code=8`）保留原回执及状态核对结果，不当作确定的密码错误。同一连接已有完整接入参数时可保留该地址，但下一次手动或自动触发的登录仍先重新发现门户：新的完整路由优先；新发现仅有弱接入信息时，只在 origin、路径及当前无线连接上下文均与保留地址一致时，才可退回原完整路由。连接、网卡参数或接入上下文改变后，不跨上下文复用旧地址。普通明确拒绝仍清除旧路由；“已在线”（`ret_code=2`）却实际离线或无法确认时，也重新发现，不能继续钉住弱缓存。

这里的 route-quality 只按当前 IP、MAC、接入设备名称及 NAS 地址是否完整来判断登录路由质量，不等同于自助服务使用的原始 NAS 绑定证明。不得把缓存地址、补写后的查询参数或完整性检查结果复用为精准注销的授权证据。学校暂时异常与接入状态可能变化，提示可以稍后重试，不设强制固定冷却时长，也不在缺少证据时断言学校正在限流。


学生网与教师网的注销统一通过学校自助服务执行。使用当前表单对应的账号密码登录管理会话，在该账号的设备列表中精确选择本机、二次读取同一会话，再提交一次下线请求。提交后在有总期限的短时窗口内核对本机认证状态与目标会话，按证据报告成功、失败或无法确认；未知结果不自动重发。操作结束后退出管理网页会话。管理服务已登录且设备列表中未匹配本机时，不能据此宣布设备在所有账号下均已离线，须结合当前设备的状态作提示。

目标选择必须保留当前 IP、物理 MAC、账号归属和完整无线环境校验。对于当前 IP 唯一、MAC 缺失或全零的会话，须取得绑定当前网卡读取的原始学校 NAS 重定向证明，核对本机 IP、MAC、接入设备名称及 NAS 地址；不得用改写后的 URL 充当证据。证明最多有效 10 秒，提交前及慢连接建立后均须重新验证。有效不同 MAC、重复目标或证明不足时拒绝操作；不会批量下线其他设备。

双读列表、绑定证明及切网 guard 属于提交前的安全核对。注销确认共享有限的时间预算，连接和响应读取均须服从总期限；不能只给重试循环计时，却让单次网络请求无限拖长。成功需要一致的本机离线证据，不以单次瞬时离线、所选账号中没有匹配项或服务器接受请求作为完成依据。状态检测只读，不触发认证、普通注销或额外下线请求。

Wi-Fi 监听仅用于本地连接显示、自动弹出与选中账号的一次自动登录，不持续轮询认证状态。界面的定时刷新只读取内存快照。手动状态检测及操作后的短时核对在工作线程执行，网络变化或旧操作的迟到结果不得覆盖新连接状态。请求回执与效果确认分别记录。

## 界面响应与开发验收

WLAN 读取、账号存取及网络请求放在工作线程和状态锁外执行；状态锁仅用于保存快照和提交结果。界面读取内存快照，不等待网卡、磁盘或网络 I/O。网络变化和退出仍使旧操作失效，产品提供手动状态检测，不提供取消或网络自检动作。

实际效果验收在独立开发脚本与真实校园网环境中完成，包括登录后外网可达、注销后接入断开、其他设备保留及再次登录；长时间持续观察和外网效果验收保留在独立开发脚本，产品只执行有总期限的短时状态确认。合成测试用于协议、安全边界和界面回归，不能替代现场验收，也不能把接口返回成功直接写成已现场验证成功。

## 自动化检查

先安装开发或构建依赖，再运行公开仓库自带的合成测试：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe research/run_offline_tests.py
.\.venv\Scripts\python.exe research/ui_smoke.py
.\.venv\Scripts\python.exe research/ui_smoke.py --hidden
```

默认测试不读取真实账号、不提交校园网认证。它明确排除25项依赖本机门户抓取的集成检查，并在结果中逐项列出排除范围；实际运行的测试有任何跳过、失败或错误都不能满足交付条件。

维护者若自行准备所需六份本地门户素材，可显式运行：

```powershell
.\.venv\Scripts\python.exe research/run_offline_tests.py --with-local-captures
```

素材位于 `.local/deep-audit/live-capture/` 下五份脚本及 `.local/portal-logout-audit/a79.htm`。缺失时此模式会明确失败，不会自动访问校园网或把未执行的检查算作通过。素材和生成报告均不进入 Git。
