<h1 align="center">矿大校园网登录器</h1>

用于中国矿业大学校园 WiFi 的 Windows 登录工具，支持保存多个账号、登录、注销、检测状态和连接后自动弹出。

**当前版本：v1.8.3，约 10.90 MB。**

[下载 Windows 版](https://github.com/AugustT666/cumt-campus-login/releases/tag/v1.8.3) · [更新记录](CHANGELOG.md)

## 下载与运行

支持 Windows 10 / 11，需要系统已安装 WebView2 Runtime，通常系统已自带无需额外安装。

在下载页选择 `cumt-campus-login-v1.8.3.exe`，下载后直接打开，无需安装 Python。

目前提供 Windows 版，Mac 和 Linux 版计划中。

## 使用方法

1. 连接 **CUMT_Stu**，填写账号、密码并选择登录网络，点击“登录”。连接 **CUMT_Tec** 时无需选择登录网络。
2. 如需保存账号，点击“保存”；下次可从“已保存账号”中选择。
3. 注销时使用当前填写的账号密码，通过学校自助服务下线本机，并短时确认注销结果。更换账号前，请先用原账号注销。
4. 点击网络名称旁的“检测状态”，可查看当前登录状态；检测不会更改登录或注销状态。

## 自动弹出与退出

开启自动弹出后，连接校园网（CUMT_Stu/CUMT_Tec）会自动弹出登录器，并用选中的已保存账号尝试登录一次。此时监听器仍在后台运行，点“退出”则完全退出并关闭弹出监听。

开启该功能时，关闭窗口会继续在后台监听。没有已保存账号时，弹出后可手动填写。

## 升级

先在旧程序中点击“退出”，再用新 EXE 替换旧文件。原来保存的账号和设置会继续保留。

## 使用提示

- 注销后会显示成功、失败或暂时无法确认；无法确认时可稍后点击“检测状态”。
- 检测反映当时的状态；若注销后又自动在线，可检查学校自助服务的无感知认证或其他自动登录设置。
- 认证超时不代表密码错误；可先检测状态，学校暂时异常时稍后重试。
- 登录失败时先核对账号和所选登录网络，并留意程序中的认证时段提示。
- 若提示系统拒绝连接，可检查安全软件的出站权限；如正在使用 Tailscale Exit Node、其他 VPN 或代理，也可尝试暂时停用后重试，未使用则跳过。
- 注销只处理该账号下能核对为本机的连接，不处理其他设备。已登录却找不到该账号的本机记录时，请核对当前在线账号。
- 需要验证码或无法核对设备时，可到[校园网自助服务](http://202.119.196.6:8080/Self/dashboard)手动处理。

## 账号与隐私

保存的账号密码在本机由当前 Windows 用户加密保护。登录及自助下线时，必要信息只提交给学校的认证或自助服务。

请仅在自己的 Windows 账户中保存账号。
