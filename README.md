## 运行与使用

需要 Windows、WebView2 Runtime，以及系统已有的 Edge 或 Chrome 浏览器。

连接 CUMT_Stu，填写账号、密码并选择登录网络后点击“登录”。连接 CUMT_Tec 时可手动登录，无需选择登录网络。已在线更换账号时请先注销。

本版连接后自动弹出和单次自动尝试仅覆盖 CUMT_Stu。点击“退出”完全结束程序。保存的密码由当前 Windows 用户在本机加密保护。

Mac 和 Linux 版计划中。
